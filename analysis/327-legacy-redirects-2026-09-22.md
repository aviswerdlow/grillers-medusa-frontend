# Legacy redirect manifest — #327

Tracking: https://github.com/aviswerdlow/grillers-pride-strategy/issues/327

A read-only graph crawl started at `https://www.grillerspride.com/Home.jsp` on September 22, 18:50 UTC and completed at 19:04 UTC. It enumerated 639 URLs: 375 product URLs (including alternate slugs for the same ListID), 201 category URLs and 63 informational/alias URLs. All product and category pages returned HTTP 200. Thirteen malformed relative `/SPD/WSWrapper.jsp` links returned HTTP 500; their correctly rooted informational pages returned 200. These failures remain in the inventory rather than being erased.

`src/lib/data/legacy-redirect-manifest.json` contains every URL, query, source hash, ListID, disposition, destination or specific owner/input. `legacy-listid-sku-map.json` bundles the current CMS identity and SKU map, cross-checked against public Medusa membership. The join uses ListID, never a guessed product title or a seasonal SKU prefix. The loader refuses duplicate identities, internal/RM items, absent public membership and disagreeing CMS/Medusa handles or ListIDs.

The original 373 rules redirect 307 verified product identities, 45 equivalent categories and 21 home/informational aliases. The crawled `/Home.jsp?refresh=true` row remains in the 639-URL inventory as `covered`: the unconditional `/Home.jsp` rule already redirects it, so no shadowed rule is emitted. Avi [approved a default navigation policy](https://github.com/aviswerdlow/grillers-pride-strategy/issues/327#issuecomment-5798106689) for the other 265 rows, based on [strategy PR #404's complete preview](https://github.com/aviswerdlow/grillers-pride-strategy/pull/404). This follow-up emits 68 missing-ListID product pages to the closest current category, 156 unmatched categories to a broader current collection, and 41 orphan pages to the closest current public page. These are navigational fallbacks, not claims of equivalent products, promotions, certifications, inventory or delivery dates. The original 373 destinations and source identities remain unchanged. The manifest now emits 638 rules and retains one `covered` row; it emits no homepage fallback for the 265 policy rows and no invented 410.

`next.config.js` consumes only resolved rows. Fixture tests exercise all emitted paths with Next's own route matcher, exact query semantics under both URL encodings, mixed case, stable direct-product identities, policy fallback counts, unsafe destinations, duplicates and loops. Rules use permanent redirects. Existing current handles and unrelated redirects are retained. The 30 distinct policy destinations each returned HTTP 200 on the existing Vercel production host on September 23. The September 23 review refinement routes the duck category to `kosher-duck`, mozzarella to `kosher-cheese`, and the biltong category and two unmatched biltong products to `kosher-specialty-charcuterie`; the verified direct biltong product still resolves to its PDP. Exact-head preview one-hop and canonical checks are separate acceptance evidence; Draft #77's canonical-host decision still governs final-host indexing.
