# Indexing and canonical policy — #328

Tracking: https://github.com/aviswerdlow/grillers-pride-strategy/issues/328

An indexable Production build requires an explicit HTTPS origin in `NEXT_PUBLIC_CANONICAL_BASE_URL`, `NEXT_PUBLIC_PRODUCTION_BASE_URL`, or `NEXT_PUBLIC_BASE_URL`, in that order of precedence. Vercel Production currently has `NEXT_PUBLIC_BASE_URL=https://grillers-medusa-frontend.vercel.app`, so this PR can deploy with the current canonical, metadata, social URLs, robots and sitemaps. At cutover, an approved `NEXT_PUBLIC_CANONICAL_BASE_URL` changes the canonical host by configuration without another source change. The .com apex-versus-www decision remains Avi's #339 input; this source change does not choose it.

A Production build with no configured HTTPS origin fails at config load unless Avi has approved a non-indexable Production and the operator sets `GP_PRODUCTION_NOINDEX_CONFIRMED=true`. That opt-in retains noindex, disallow-all robots and an empty sitemap. Inspect all three URL variables on Vercel Production before deployment. Values must be origins without credentials, path, query or fragment; a trailing path fails the build. The current Vercel alias is allowed because it is explicitly configured for Production, not because of a hard-coded host exception.

A Vercel preview uses its own environment URL, even if production values were copied into its environment. Preview/non-production responses have `X-Robots-Tag: noindex, nofollow`, robots disallows `/`, and sitemap generation publishes no URLs. This response header also covers child pages that supply their own index metadata. Production indexing follows the configured HTTPS origin, including the current Vercel production alias.

Production robots and response headers exclude account, cart, checkout, order and API paths, including `/us/` and other two-letter locales. Robots' exact private roots use `$` and descendants use `/`, so public `/us/holidays/order-deadlines` and `/us/page/order-sms-*` are not blocked. Sitemap filtering rejects private paths independently, along with percent-encoded private names, legacy JSP/SPD paths, query/fragment URLs and duplicates. Authentication and existing private-page noindex metadata are retained. Public sitemap product eligibility still uses the existing lifecycle/internal-item filters and source-failure rules.

Validation includes the Production build guard, current Vercel alias, configuration-only cutover, exact-root robots matches that retain public order-information URLs, canonical precedence, preview isolation, Next header-route matching, malformed origins, preview empty sitemap, production private filtering and existing catalogue failure behavior. Focused checks and exact-head CI are linked from #328. Preview HTTP evidence does not establish Production host indexing; Avi's cutover host decision, Vercel environment readback and Search Console remain #339 execution checks.
