# Indexing and canonical policy — #328

Tracking: https://github.com/aviswerdlow/grillers-pride-strategy/issues/328

An indexable Production build requires `NEXT_PUBLIC_CANONICAL_BASE_URL` set to Avi's approved HTTPS origin outside `vercel.app`. It wins over `NEXT_PUBLIC_PRODUCTION_BASE_URL` and `NEXT_PUBLIC_BASE_URL` for page metadata, social URLs and sitemaps. A Production build without that explicit indexable host fails at config load unless Avi has approved a non-indexable `vercel.app` Production and the operator sets `GP_PRODUCTION_NOINDEX_CONFIRMED=true`. That opt-in retains noindex, disallow-all robots and an empty sitemap; it does not itself approve a merge. Inspect all three URL variables on Vercel Production before deployment, because a stale fallback could still supply metadata in the approved noindex lane. Values must be origins without credentials, path, query or fragment; a trailing path fails the build. The .com apex-versus-www decision remains Avi's #339 input; this source change does not choose it.

A Vercel preview uses its own environment URL, even if production values were copied into its environment. Preview/non-production responses have `X-Robots-Tag: noindex, nofollow`, robots disallows `/`, and sitemap generation publishes no URLs. This response header also covers child pages that supply their own index metadata. A production deployment becomes indexable only with an explicit HTTPS canonical host outside vercel.app.

Production robots and response headers exclude account, cart, checkout, order and API paths, including `/us/` and other two-letter locales. Robots' exact private roots use `$` and descendants use `/`, so public `/us/holidays/order-deadlines` and `/us/page/order-sms-*` are not blocked. Sitemap filtering rejects private paths independently, along with percent-encoded private names, legacy JSP/SPD paths, query/fragment URLs and duplicates. Authentication and existing private-page noindex metadata are retained. Public sitemap product eligibility still uses the existing lifecycle/internal-item filters and source-failure rules.

Validation includes the Production build guard, exact-root robots matches that retain public order-information URLs, canonical precedence, preview isolation, Next header-route matching, malformed origins, preview empty sitemap, production private filtering and existing catalogue failure behavior. Focused checks and exact-head CI are linked from #328. Preview HTTP evidence does not establish Production host indexing; Avi's host decision, Vercel environment readback and Search Console remain #339 execution checks.
